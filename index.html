URL shortener & analytics

Linkly

A link-in-bio platform with short URLs, public profiles, and a creator dashboard for click analytics.

  • Redirects and analytics run separately. An indexed PostgreSQL lookup checks link and account status. Redis Streams queues clicks for a background worker.
  • Replays preserve click counts. The worker counts each event UUID once and acknowledges it after the database commits. A bounded memory queue handles temporary Redis outages.

Checkout & payment recovery

Resilient Checkout API

A Spring Boot checkout service that reserves stock in PostgreSQL and reconciles uncertain simulated payments.

  • Safe retries and inventory writes. Customer-scoped idempotency returns the existing order on a replay. Row locks protect the last unit from concurrent buyers.
  • Recovery across restarts. A scheduled worker settles pending orders from a durable payment ledger. Confirmed declines restore stock transactionally.

✓ 14 passing tests, including 11 PostgreSQL integration tests

  • Spring Boot 4.1

Version control & developer tools

MiniGit

A local version-control system in Go with a CLI and an embedded React dashboard backed by the same repository engine.

  • Snapshot storage and merge. Stores file contents by hash, commits staged snapshots, and uses the commit graph for fast-forwards and file-level three-way merges.
  • Guarded checkouts. Detects collisions with untracked files and keeps backups to roll back ordinary filesystem errors.
