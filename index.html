URL Shortener & Click Analytics

A link-in-bio platform with custom short URLs and a dashboard for click analytics. The Spring Boot API resolves redirects from PostgreSQL and processes click events in the background.

Replay-Safe Click Analytics

A worker consumes clicks from Redis Streams and records the event and counter update in one PostgreSQL transaction. It acknowledges the event after commit, so replayed clicks leave totals unchanged.

MiniGit (mgit)

Local Version Control in Go

A version-control tool that tracks folders, stages snapshots, and merges branches. The Go CLI and React dashboard share the same repository engine.

Content-Addressable Storage

File contents are stored by hash, so identical contents can share a blob across paths and commits. Each commit records a snapshot and its parent commit IDs.

File-Level Three-Way Merge

The engine fast-forwards when possible. For divergent branches, it compares both snapshots with their common base and flags conflicting changes to the same file.

Guarded Working-Tree Updates

Checkout detects collisions with untracked files, validates incoming blobs, and keeps backups so ordinary filesystem errors can be rolled back.

Embedded Dashboard

The Go executable embeds the React and TypeScript dashboard for staging, branches, and searchable commit history. The engine and HTTP API have 13 Go tests.
